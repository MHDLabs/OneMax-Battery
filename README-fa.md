# OneMax Battery

یک ابزار سبک با زبان Rust برای خواندن وضعیت باتری ماوس‌های بی‌سیم ۲٫۴ گیگاهرتز از طریق رابط HID در لینوکس.

**وضعیت:** توسعه اولیه. هدف نخست، گیرنده ماوس ONE MAX OM-W45B با شناسه USB برابر با **1EA7:0066** است.

## قابلیت‌ها

- بازکردن رابط HIDRAW مربوط به ماوس.
- بررسی شناسه USB پیش از ارسال درخواست.
- ارسال یک درخواست وضعیت باتری با Report ID برابر با B5 و فرمان 01.
- انتظار حداکثر ۷۵۰ میلی‌ثانیه برای پاسخ.
- نمایش درصد باتری گزارش‌شده.
- بدون ماژول کرنل و بدون تغییر تنظیمات ماوس.

## مشاهده سخت‌افزاری

در آزمایش واقعی روی گیرنده هدف، این درخواست ارسال شد:

```text
TX: B5 01 00 00 00 00 00 00
RX: B5 01 01 38 2E FF 09 70
```

مقدار مشاهده‌شده باتری برابر با 0x38 یا ۵۶ ده‌دهی بود. ساختار پاسخ فعلاً بر پایه این آزمایش موفق و یک مرجع پروتکل مشابه پیاده‌سازی شده است. برای اطمینان بیشتر، آزمایش در سطح باتری‌های مختلف و پس از اتصال مجدد لازم است.

## ساخت از سورس

به Rust و Cargo نیاز دارید:

```sh
cargo test
cargo build --release
```

## اجرا

ابتدا رابط HID ماوس را پیدا کنید؛ رابط صفحه‌کلید را انتخاب نکنید:

```sh
ls -l /dev/hidraw*
```

سپس:

```sh
sudo ./target/release/one-max-battery /dev/hidrawX
```

برنامه به دسترسی خواندن و نوشتن روی فایل hidraw نیاز دارد. پیش از ارسال درخواست، شناسه HID را از sysfs بررسی می‌کند و روی دستگاهی با شناسه متفاوت درخواست نمی‌فرستد.

## فایل باینری آماده

با ایجاد تگ نسخه، برای نمونه v0.1.0، گیت‌هاب اکشنز باینری Linux x86_64 را می‌سازد و در بخش Releases منتشر می‌کند. هر انتشار شامل فایل اجرایی و SHA256SUMS است.

## وضعیت توسعه

این ابزار یک درایور آزمایشی در فضای کاربر است، نه ماژول کرنل. فعلاً فقط شناسه گیرنده آزمایش‌شده و یک درخواست باتری را پشتیبانی می‌کند. شناسایی خودکار دستگاه، پایش دوره‌ای، یکپارچه‌سازی با دسکتاپ و مدل‌های دیگر هنوز پیاده‌سازی نشده‌اند.
